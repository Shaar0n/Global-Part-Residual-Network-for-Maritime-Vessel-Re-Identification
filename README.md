# Global-Part-Residual-Network-for-Maritime-Vessel-Re-Identification
 Maritime vessel re-identification with a ResNet-50 backbone, trained across three increasingly sophisticated stages (baseline -> global+part -> GeM/BNNeck strong-baseline v2).   ▎ From-scratch CMC/mAP eval, k-reciprocal re-ranking, flip-TTA, and a Streamlit retrieval demo. Best: 83.6% mAP / 92.1% Rank-1.
